Como Publicar no GitHub (Pages & Projects)

1 Publicar o Painel Interativo no GitHub Pages (Online Grátis)

Este painel foi estruturado sem dependências complexas (HTML, CSS e JS modernos). Basta enviar para o repositório no GitHub: 

# 1. No terminal da pasta do projeto:
git init
git add .
git commit -m "feat: Painel Kanban de Gestao de Portfolio CBMMT"
git branch -M main
git remote add origin https://github.com/SEU-USUARIO/cbmmt-portfolio.git
git push -u origin main

Em seguida, no seu GitHub vá em: Settings > Pages > Branch: main > Save. Em 60 segundos o painel estará acessível no link público:
https://SEU-USUARIO.github.io/cbmmt-portfolio/

2 Usar o GitHub Projects (Kanban Nativo do GitHub)

Se sua equipe deseja gerenciar as tarefas diretamente pelas Issues e pelo GitHub Projects (v2):

  • No repositório, clique na aba Projects > New project > Board.
  • Crie os Custom Fields: Valor (Number), Fonte (Single select), Unidade (Single select), Sprint (Iteration).
  • Configure as colunas recomendadas (já prontas na pasta .github/ que criamos neste projeto).
  • Os modelos de Issue para abertura de novos projetos, editais e tarefas de sprint já foram gerados na pasta .github/ISSUE_TEMPLATE/!
